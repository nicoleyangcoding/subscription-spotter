# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-09

### Added
- `--since DATE` to only use transactions on or after a date

## [0.1.0] - 2026-10-29

### Added
- Detect weekly, every 2 weeks, monthly, 3-monthly, 6-monthly and yearly charges
- Automatic detection of CSV columns, date formats, number formats and separators
- Price change and possibly-cancelled flags
- Table, JSON and CSV output
- Made-up sample statement for trying it safely
